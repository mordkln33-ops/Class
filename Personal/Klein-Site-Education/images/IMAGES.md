# Images checklist

Save each image in this folder with the **exact file name** below. The "Image goes here"
placeholder disappears as soon as the file exists. No code changes are needed.

Tips:
- Export JPGs at about 75–80% quality. Aim for under 200 KB each.
- Keep the aspect ratio listed so nothing gets cropped awkwardly.
- Use photos you have rights to (your own, the client's, or licensed stock).
- If you change what a photo shows, update its `alt` text in the HTML to match.
