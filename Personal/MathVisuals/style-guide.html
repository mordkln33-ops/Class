Design system

MathVisuals style guide

One set of colors, type and components shared by the home page and every tool. The tokens live at the top of assets/css/site.css; tool stylesheets only reference them.

  • Projector first. Body text ≥ 7:1 contrast (WCAG AAA), UI boundaries ≥ 3:1, no separating line thinner than 2px.
  • One typeface. Atkinson Hyperlegible, built so look-alike characters (I l 1, 0 O) stay distinct at a distance.
  • Fluid size. Tool pages use a projector root size that grows from 16px to 28px with the screen.
  • Two full palettes. Light and dark mode are designed separately, not inverted.

Typography

Aa Bb 0O Il1 −3 ½

Atkinson Hyperlegible, Regular 400 and Bold 700, with system sans-serif as a fallback. Numbers and equations use the same face with font-variant-numeric: tabular-nums so columns line up. Code-like input (ordered pairs, equations in the Graphing Explorer) uses the system monospace stack --font-mono.

Type scale

Sizes are in rem, so they follow the root size: about 18px on a laptop for reading pages, and the fluid projector size (16–28px) on tool pages.

--fs-4xlHero headingHome hero only (fluid)
--fs-3xlSection heading2.3rem · h2 on reading pages
--fs-2xlTool title1.8rem · tool h1, big values
--fs-xlCard heading1.45rem · h3, equations
--fs-lgLead paragraph1.2rem · leads, big buttons
--fs-mdBody text and buttons1rem · default
--fs-smSecondary text and hints0.9rem
--fs-xsOVERLINE LABEL0.8rem · smallest allowed

Line height: --lh-tight 1.15 for headings and big numbers, --lh-snug 1.3 for tool panels, --lh-base 1.6 for paragraphs. Uppercase labels use --tracking-label (0.08em).

Borders and corners

  • --radius-sm 8pxInputs, chips
  • --radius-md 12pxButtons, inner cards
  • --radius-lg 18pxPanels, cards, modals
  • --radius-pillTags, toggles
  • --border-width-thick 3pxSelected, active
  • --border-width-accent 6pxColor bands, callouts

Every visible boundary is --border-width (2px). Shadows are subtle (--shadow-sm/md/lg). On a projector, borders carry the structure, not shadows.

Panel

Panel label

Tool panels are --color-surface with a 2px --color-border outline and --radius-lg corners. Panel labels are small uppercase overlines in --color-ink-muted.

Dark-mode toggle

Lives in the header of every page. It stores the choice in localStorage (mv-theme); until then it follows the operating system. theme-init.js applies the theme before the first paint, and site.js fires a themechange event so tools that draw in JavaScript can redraw.
