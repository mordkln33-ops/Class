Teacher notes

A horizontal number line for integer operations

This is the textbook-style version of the integer number line: negatives on the left, positives on the right, and a bar that grows or shrinks as you add and subtract.

How to use it in class

  1. Type a number into Add or Subtract. Negative numbers and decimals both work.
  2. Press Submit. The bar slides to the new value and turns red when the value is below zero.
  3. Talk through the history. Each step is recorded as an equation, so students can check the pattern behind rules like a − (−b) = a + b.

Moving left and right

On a horizontal number line, “greater” means “further right.” Ask students to say which way the bar will move before you submit: adding a positive or subtracting a negative moves right, and adding a negative or subtracting a positive moves left. Every whole number from −20 to 20 is marked, with bold labels every five.

Projector tip: the number line spans most of the screen width, so it stays readable from the back of the room. On phones, only the labels at multiples of five are shown so the scale doesn't get crowded.

Frequently asked questions

What is the difference between this and the vertical version?

Only the drawing. Both pages use the same controls and math. The vertical version suits temperature and elevation problems; this one matches textbook number lines.

Does it work on an interactive whiteboard?

Yes. The inputs and buttons are large touch targets, and the page works in any modern browser with no installation.
