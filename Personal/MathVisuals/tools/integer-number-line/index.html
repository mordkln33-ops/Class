Teacher notes

Teaching integer addition and subtraction on a number line

Students often memorize “two negatives make a positive” without seeing why. This number line makes every integer operation visible: the bar rises when the value goes up, falls when it goes down, and turns red the moment it drops below zero.

How to use it in class

  1. Start at zero. The current value begins at 0, marked by the line across the middle of the scale.
  2. Add or subtract any number. Type a positive or negative number into Add or Subtract and press Submit (or Enter). Ask the class to predict whether the bar will go up or down before you press it.
  3. Watch the fill move. The fill always runs from −20 up to the current value, so students see the size of the change, not just the answer.
  4. Read the history. Every step is written out as an equation such as 4 − (−3) = 7, newest first, so you can go back over the sequence together.

Why subtracting a negative goes up

Enter the same number in both boxes, once as a positive and once as a negative, and compare. Adding −3 and subtracting 3 move the bar the same distance down; subtracting −3 moves it up. Seeing the bar climb is usually the moment the rule stops being a rule and starts making sense.

Vertical or horizontal?

The vertical version works like a thermometer or an elevator, which helps with temperature, elevation and bank-balance word problems. The horizontal number line matches the way number lines appear in most textbooks. Both pages share the same controls.

Projector tip: the value can go past the ends of the scale. The math keeps going and a note appears; only the drawing stops at −20 or +20. That is a good opening for talking about how a number line continues forever.

Frequently asked questions

Is this integer number line free to use?

Yes. It is free, needs no account or download, and runs in any modern web browser on a laptop, interactive whiteboard, Chromebook, tablet or phone.

Can I enter decimals?

Yes. Any number can be added or subtracted, including decimals, which makes the tool useful for rational-number operations too.

What grade levels is this for?

It is designed for grades 6 and 7, where students first add and subtract integers (Common Core 6.NS.C.5–6 and 7.NS.A.1). It also works well as review in Algebra 1.
