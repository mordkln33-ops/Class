About this page & network filters

This is a private list where family and friends write down their Rosh Hashanah flight times to and from Eretz Yisroel, so that people on the same flight can arrange to travel together. It is not a public website and it is not listed in search engines.

What this page does not do

  • ✓No advertisements of any kind.
  • ✓No tracking, no analytics, no cookies.
  • ✓No images, video, or audio — the page is text only.
  • ✓No links out to any other website — only a phone number and email address for the person running the list.
  • ✓No chat, no messaging between strangers, no file uploads.
  • ✓No accounts, passwords, or payments.
  • ✓No outside scripts or web fonts — it uses only the fonts already on your device.

For whoever manages your filter

Besides the server this page is served from, it connects to exactly one other address — its database:

Allowing that one address is enough for the page to work. Nothing else is ever requested, so no other domain needs to be opened up.

What gets stored

Only what people type into the form: name, phone number, flight day, time, airline and airport, and an optional comment. Anyone with the link can read, add, and edit entries, so treat it the way you would a shared paper list — put in a phone number only if you are happy for everyone on the list to see it.
